## 2. Data collected by the application

The application does not collect, store, sell, or use personal data for analytics, advertising, profiling, or marketing purposes.

For the sole purpose of verifying the user’s subscription entitlement, the application reads the Autodesk user ID associated with the account currently signed in to Autodesk Navisworks.

The application sends the following information directly to the Autodesk Entitlement API over an encrypted HTTPS connection:

- the Autodesk user ID of the signed-in user;
- the Autodesk Marketplace App ID assigned to the application.

No Autodesk password, payment information, authentication credential, model data, project data, or document content is collected or transmitted by the application.

## 3. Purpose and use of the data

The Autodesk user ID is used exclusively to determine whether the user has a valid entitlement to access the application through the Autodesk Design and Make Marketplace.

The entitlement response returned by Autodesk indicates whether the user is authorized to use the application. If the entitlement is not valid, access to the application’s paid features is disabled.

The data is not used for any other purpose.

## 4. Data sharing and third parties

The application does not share personal data with advertising networks, analytics providers, marketing platforms, or other third parties.

The Autodesk user ID and Marketplace App ID are transmitted directly to Autodesk solely for entitlement verification.

Autodesk processes this information in accordance with its own privacy and data-protection policies. The Publisher does not control Autodesk’s independent processing or retention of information submitted to the Autodesk Entitlement API.

## 5. Data retention and deletion

The Publisher does not receive or retain the Autodesk user ID.

The entitlement result is stored temporarily in the application’s memory for the duration of the current Autodesk Navisworks session. It is cleared when:

- Autodesk Navisworks is closed;
- the application session ends; or
- the user manually requests a new license verification.

The application does not create a permanent local or remote database containing personal data.

Because the Publisher does not retain personal data, there is normally no Publisher-held personal data requiring deletion.

## 6. Consent and user choices

The entitlement verification is necessary to determine whether the user is authorized to use the subscription-based application.

Users may stop the entitlement verification and revoke their use of the application by:

- uninstalling the application; or
- signing out of their Autodesk account in Autodesk Navisworks.

Users may contact the Publisher to request confirmation of whether any personal data concerning them is held or to request its deletion.

Requests should be sent to:

**marquis.vincent67@gmail.com**

Since the Publisher does not retain personal data, the Publisher will normally confirm that no personal data is held.

## 7. Data security

The entitlement request is transmitted to Autodesk through an encrypted HTTPS connection.

The application does not store Autodesk passwords, payment details, authentication credentials, or entitlement information in permanent storage.

## 8. Children’s privacy

The application is intended for professional use and is not directed at children. The Publisher does not knowingly collect personal data from children.
